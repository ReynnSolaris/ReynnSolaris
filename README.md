# Rainn

Solo developer behind [EmberFrameworks](https://emberframeworks.xyz). Mostly games, the engines and
tools under them, and the backend that keeps them online. C++, C#, Java, TypeScript, Python, Kotlin.

## Engine and games

| | |
|---|---|
| [astral-engine](https://github.com/ReynnSolaris/astral-engine) | 2D/3D engine scripted in Luau. raylib + Dear ImGui, immediate-mode draw and UI, ready-made ARPG/RPG/RTS components, dedicated servers, server-authoritative replication, encrypted saves and shipping archives. CMake. |
| [pgquest](https://github.com/ReynnSolaris/pgquest) | Learn PostgreSQL by repairing a broken database. 30 levels on real Postgres in the browser via PGlite. React + Vite. |

## Minecraft

| | |
|---|---|
| [wisp-and-willow](https://github.com/ReynnSolaris/wisp-and-willow) | Magic and logistics mod for NeoForge 1.21.1. Chalk circles, a current called Fluxia, a willow coaxed out of still water. |
| [banned-items](https://github.com/ReynnSolaris/banned-items) | Server-side NeoForge mod. Bans items by full fingerprint (id plus components) and destroys them wherever they appear. |
| [astrium-skyblock](https://github.com/ReynnSolaris/astrium-skyblock) | Paper plugin core for a sci-fi skyblock: shops, zones, NPCs, minions. |
| [warden-bot](https://github.com/ReynnSolaris/warden-bot) | Moderation, verification and automod bot for the Wisp & Willow Discord. discord.py + SQLite. |
| [nbt-studio](https://github.com/ReynnSolaris/nbt-studio) | NBT editors in C#, one on Avalonia and one on Direct3D 11 + ImGui. |

## Tools

| | |
|---|---|
| [quest-log-sorter](https://github.com/ReynnSolaris/quest-log-sorter) | F4SE plugin. Grouped, collapsible Pip-Boy quest log with objectives nested under their quests; DLC and mod quests get their own sections. |
| [gif-maker](https://github.com/ReynnSolaris/gif-maker) | Chrome/Brave extension. Hover a video, pick a range on a thumbnail timeline, save a GIF. |
| [discord-miner-bot](https://github.com/ReynnSolaris/discord-miner-bot) | Incremental mining game as a Discord bot. discord.js + MySQL. |

## Closed source

Ember Works (operations console), PULSE (SEO rank tracker), and the portal that handles auth,
billing and DLC keys for Astral games are EmberFrameworks products and stay private.
